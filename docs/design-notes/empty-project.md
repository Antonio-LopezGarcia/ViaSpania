# Estado de proyecto vacío

ViaSpania distingue entre el estado inicial sin proyecto y un proyecto abierto, incluso si todavía no contiene puntos ni modelo. Sin proyecto, el encabezado muestra «Proyecto vacío» o «Empty project» en dos líneas. Guardar permanece desactivado hasta que se cree o se abra un proyecto.

Al crear, abrir o cargar automáticamente el último proyecto, el encabezado muestra inmediatamente su nombre. El encabezado ofrece únicamente las acciones Nuevo proyecto, Abrir proyecto y Guardar proyecto.
